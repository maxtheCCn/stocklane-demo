Shopify connection

Not connected

Stocklane is running on a local development store. Everything works end to end, but nothing is published to Shopify and no real orders are received.

  1. Create an app in the Shopify Partner Dashboard (or Dev Dashboard) and a development store.
  2. Copy the app’s Client ID and Client secret into SHOPIFY_API_KEY and SHOPIFY_API_SECRET in the .env file.
  3. Run the app through the Shopify CLI so SHOPIFY_APP_URL is a public https URL (currently http://localhost:3000).
  4. Install the app on your store. Stocklane switches to the connected store automatically.

Credentials stay on the server in environment variables and are never sent to the browser.
