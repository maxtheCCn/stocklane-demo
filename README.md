# Stocklane demo

A read-only demo of Stocklane, a Shopify dropshipping automation app.

Everything here is static: pre-rendered pages plus the data each page needs. There is no server and
no database, so nothing you click is saved — saving shows a "read-only demo" notice instead.

Generated by `scripts/static-export.mjs` in the Stocklane repository; edit the app, not these files.
