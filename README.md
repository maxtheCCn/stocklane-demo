# Stocklane demo

A read-only demo of Stocklane, a Shopify dropshipping automation app. Browse it at
**https://maxtheccn.github.io/stocklane-demo/**

Everything here is static: pre-rendered pages plus the data each page needs. There is no server and
no database, so nothing you click is saved — saving shows a "read-only demo" notice instead.

Generated from the application with `scripts/static-export.mjs` in the Stocklane repository.
